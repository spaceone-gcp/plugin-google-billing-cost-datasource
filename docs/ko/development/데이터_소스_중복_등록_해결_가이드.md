# 데이터 소스 중복 등록 해결 가이드

## 개요

SpaceONE에서 데이터 소스를 등록할 때 발생하는 `ERROR: Tried to save duplicate unique values. (keys = ['name', 'domain_id'])` 에러의 원인과 해결 방법을 설명합니다.

## 에러 원인

이 에러는 다음과 같은 상황에서 발생합니다:

1. **동일한 이름의 데이터 소스가 이미 존재**: 같은 도메인 내에서 동일한 `name`을 가진 데이터 소스가 이미 등록되어 있는 경우
2. **중복 등록 시도**: 같은 설정으로 데이터 소스를 여러 번 등록하려고 하는 경우
3. **이름 충돌**: 서로 다른 설정이지만 같은 이름을 사용하는 경우

## 해결 방법

### 1. 기존 데이터 소스 확인

SpaceONE UI에서 기존에 등록된 데이터 소스를 확인합니다:

```bash
# SpaceONE CLI를 사용하는 경우
spacectl list data-source

# 또는 UI에서 확인
# Cost Analysis > Data Sources 메뉴에서 확인
```

### 2. 고유한 이름 사용

각 데이터 소스마다 고유한 이름을 사용합니다:

#### 현재 프로젝트의 명명 규칙

```yaml
# BigQuery 데이터 소스
name: Aramco GCP Cloud Billing BigQuery v2.0
name: Aramco GCP Cloud Billing BigQuery Method1 v2.0

# GCS 데이터 소스  
name: Aramco GCP Cloud Billing GCS v2.0
name: Aramco GCP Cloud Billing GCS Method2 v2.0
```

#### 권장 명명 규칙

```yaml
# 패턴: [회사명] [클라우드] [서비스] [데이터소스타입] [버전/방법]
name: "[Company] GCP Billing [DataSourceType] [Version/Method]"

# 예시
name: "Aramco GCP Billing BigQuery v2.0"
name: "Aramco GCP Billing GCS Standard v2.0"
name: "Aramco GCP Billing HTTP Export v2.0"
```

### 3. 기존 데이터 소스 삭제

중복된 데이터 소스가 있다면 삭제 후 재등록:

```bash
# SpaceONE CLI를 사용하는 경우
spacectl delete data-source -p data_source_id=[DATA_SOURCE_ID]

# 또는 UI에서 삭제
# Cost Analysis > Data Sources > 해당 데이터 소스 선택 > Delete
```

### 4. 단계별 등록 절차

1. **기존 데이터 소스 확인**
   ```bash
   spacectl list data-source --filter name="Aramco GCP"
   ```

2. **중복된 데이터 소스 삭제** (필요한 경우)
   ```bash
   spacectl delete data-source -p data_source_id=[DUPLICATE_ID]
   ```

3. **새로운 고유 이름으로 등록**
   ```bash
   spacectl exec register data-source -f register_gcp_bigquery_datasource.yaml
   ```

## 예방 방법

### 1. 이름 중복 체크 스크립트

```bash
#!/bin/bash
# check_datasource_names.sh

echo "현재 등록 파일들의 데이터 소스 이름:"
grep "^name:" register_*.yaml

echo -e "\n기존 등록된 데이터 소스 확인:"
spacectl list data-source --filter name="Aramco" --output table
```

### 2. 등록 전 검증

```bash
#!/bin/bash
# validate_before_register.sh

DATASOURCE_NAME=$(grep "^name:" $1 | cut -d' ' -f2-)
echo "등록하려는 데이터 소스 이름: $DATASOURCE_NAME"

# 기존 데이터 소스 확인
EXISTING=$(spacectl list data-source --filter name="$DATASOURCE_NAME" --output json | jq '.results | length')

if [ "$EXISTING" -gt 0 ]; then
    echo "❌ 경고: 동일한 이름의 데이터 소스가 이미 존재합니다!"
    echo "기존 데이터 소스를 삭제하거나 다른 이름을 사용하세요."
    exit 1
else
    echo "✅ 등록 가능한 이름입니다."
    spacectl exec register data-source -f $1
fi
```

## 트러블슈팅

### 문제: 삭제 후에도 같은 에러 발생

**원인**: 데이터베이스 캐시나 인덱스 문제

**해결책**:
1. SpaceONE 서비스 재시작
2. 다른 이름으로 등록 시도
3. 관리자에게 데이터베이스 정리 요청

### 문제: UI에서는 보이지 않지만 에러 발생

**원인**: 소프트 삭제된 데이터 소스가 남아있는 경우

**해결책**:
```bash
# 모든 상태의 데이터 소스 확인 (삭제된 것 포함)
spacectl list data-source --filter name="Aramco" --include-deleted
```

### 문제: 여러 도메인에서 같은 이름 사용

**원인**: 도메인별로 고유해야 하는 제약 조건

**해결책**: 도메인명을 포함한 이름 사용
```yaml
name: "Aramco-Domain1 GCP Billing BigQuery v2.0"
name: "Aramco-Domain2 GCP Billing BigQuery v2.0"
```

## 모니터링 및 관리

### 1. 정기적인 데이터 소스 목록 확인

```bash
# 월간 데이터 소스 현황 확인
spacectl list data-source --output table > datasource_status_$(date +%Y%m).txt
```

### 2. 이름 규칙 준수 확인

```bash
# 명명 규칙 준수 여부 확인
spacectl list data-source --filter name="Aramco" --output json | \
jq '.results[] | select(.name | test("v[0-9]+\\.[0-9]+") | not) | .name'
```
