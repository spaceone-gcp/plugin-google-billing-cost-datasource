# 테스트 가이드

## 📋 개요

SpaceONE Google Cloud Billing Cost Datasource 플러그인의 **통합 테스트, 단위 테스트, 디버깅**에 대한 종합 가이드입니다.

**기반**: v1.0.9 - gRPC API 테스트 모범사례 및 문제 해결 방법 포함

## 🎯 테스트 전략 개요

### 계층별 테스트 접근법

```
┌─────────────────────────────────────────┐
│ 1. Unit Tests (단위 테스트)              │
│    - Manager 클래스 직접 테스트          │
│    - 비즈니스 로직 검증                  │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│ 2. Integration Tests (통합 테스트)       │
│    - Python gRPC 클라이언트             │
│    - 전체 API 플로우 검증               │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│ 3. E2E Tests (종단간 테스트)            │
│    - 실제 데이터 소스 연동               │
│    - 운영 환경 시뮬레이션               │
└─────────────────────────────────────────┘
```

### 테스트 우선순위

1. **Unit Tests** (최우선) - 빠르고 안정적
2. **Integration Tests** (권장) - 실제 API 동작 검증
3. **E2E Tests** (선택적) - 운영 환경 검증

### Manager 클래스 테스트

#### CostManager 테스트 예제
```python
# test/test_cost_manager.py
import pytest
from unittest.mock import Mock, patch
from src.plugin.manager.cost_manager import CostManager

class TestCostManager:
    def setup_method(self):
        """각 테스트 전에 실행"""
        self.cost_manager = CostManager()
        
    def test_get_data_bigquery_success(self):
        """BigQuery 데이터 조회 성공 테스트"""
        # Given
        options = {
            "source": "bigquery",
            "billing_export_project_id": "test-project",
            "billing_dataset_id": "billing_export",
            "billing_account_id": "123456-789012-345678"
        }
        secret_data = {"type": "service_account"}
        task_options = {"start": "2024-01"}
        
        # Mock BigQuery 응답
        mock_df = Mock()
        mock_df.iterrows.return_value = [
            (0, Mock(cost=10.5, project_id="test-project"))
        ]
        
        with patch.object(self.cost_manager.bigquery_connector, 'read_df_from_bigquery', return_value=mock_df):
            # When
            results = list(self.cost_manager.get_data(options, secret_data, task_options))
            
            # Then
            assert len(results) > 0
            assert results[0]["results"][0]["cost"] == 10.5
            
    def test_get_data_invalid_source(self):
        """잘못된 source 파라미터 테스트"""
        # Given
        options = {"source": "invalid"}
        secret_data = {}
        task_options = {}
        
        # When & Then
        with pytest.raises(ValueError, match="Unsupported source"):
            list(self.cost_manager.get_data(options, secret_data, task_options))
```

# 4. 실제 데이터 테스트 (설정 파일이 있는 경우)

## 🐛 문제 해결 및 디버깅

### GCS와 BigQuery 혼용 에러 해결

#### 문제 상황
```
ERROR: Cannot mix GCS and BigQuery configurations
```

#### 원인 분석
- `source` 파라미터와 다른 설정이 혼재
- 예: `source: "gcs"`인데 `billing_dataset_id` 설정

#### 해결 방법
```python
def validate_source_consistency(options: dict) -> None:
    """source 파라미터와 다른 설정의 일관성 검증"""
    source = options.get("source", "bigquery")
    
    if source == "bigquery":
        required_fields = ["billing_export_project_id", "billing_dataset_id", "billing_account_id"]
        invalid_fields = ["bucket_name", "base_url"]
    elif source == "gcs":
        required_fields = ["bucket_name"]
        invalid_fields = ["billing_dataset_id", "billing_account_id"]
    elif source == "http":
        required_fields = ["base_url"]
        invalid_fields = ["bucket_name", "billing_dataset_id"]
    
    # 필수 필드 확인
    missing = [f for f in required_fields if not options.get(f)]
    if missing:
        raise ValueError(f"Missing required fields for {source}: {missing}")
    
    # 잘못된 필드 확인
    invalid = [f for f in invalid_fields if options.get(f)]
    if invalid:
        raise ValueError(f"Invalid fields for {source}: {invalid}")
```

import cProfile
import pstats
from src.plugin.manager.cost_manager import CostManager

def profile_cost_manager():
    """CostManager 성능 프로파일링"""
    cost_manager = CostManager()
    
    # 프로파일링 실행

## 📊 테스트 자동화

### GitHub Actions 워크플로우

```yaml
# .github/workflows/test.yml
name: Tests

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Set up Python
      uses: actions/setup-python@v3
      with:
        python-version: '3.9'
        
    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install -r pkg/pip_requirements.txt
        pip install pytest pytest-cov
        
    - name: Run tests
      run: |
        pytest --cov=src --cov-report=xml
        
    - name: Upload coverage
      uses: codecov/codecov-action@v3
      with:
        file: ./coverage.xml
```
