### 데이터 순수성 검증 체크리스트

코드 수정 시 반드시 다음 사항을 확인해야 합니다:

#### ✅ 필수 검증 항목
- [ ] **IFNULL 사용 금지**: BigQuery 쿼리에서 `IFNULL(field, default)` 사용하지 않았는가?
- [ ] **기본값 설정 금지**: `getattr(row, "field", 0.0)` 형태의 기본값 설정하지 않았는가?
- [ ] **반올림 금지**: `round()`, `float()`, `Decimal()` 등 데이터 변환 작업하지 않았는가?
- [ ] **NULL 값 보존**: 모든 NULL 값이 그대로 보존되는가?
- [ ] **스키마 일치**: 응답 필드가 BigQuery 스키마와 100% 일치하는가?
- [ ] **중첩 구조 매핑**: RECORD 타입 필드가 정확한 경로로 매핑되었는가?
- [ ] **REPEATED 필드 처리**: 배열 필드가 JSON 문자열로 적절히 변환되었는가?

#### ⏰ 하드코딩 날짜 검증
- [ ] **절대 날짜 없음**: `2024-01-01` 같은 고정 날짜 사용하지 않았는가?
- [ ] **동적 계산**: 모든 날짜가 `datetime.now()` 기반으로 동적 계산되는가?
- [ ] **기본값 용도**: 하드코딩된 기간(365일, 5년)이 기본값 용도로만 사용되는가?

### SpaceONE 표준 응답 구조 보장

**CRITICAL**: SpaceONE 빌링 응답의 최상위 `cost` 필드는 필수 항목입니다.

모든 에러 처리에서도 다음 구조를 **반드시** 준수해야 합니다:

```json
{
  "results": [
    {
      "cost": 0.0,                       // CRITICAL: 에러 시에도 필수 필드 보장
      "usage_quantity": 0.0,             // 필수: 기본값 제공
      "provider": "google_cloud",        // 필수: 프로바이더
      "region_code": "unknown",          // 필수: 에러 시 기본값
      "product": "unknown",              // 필수: 에러 시 기본값
      "usage_type": "unknown",           // 필수: 에러 시 기본값
      "resource": "unknown",             // 필수: 에러 시 기본값
      "billed_date": "2025-10-02",       // 필수: 현재 날짜 사용
      "currency": "USD",                 // 필수: 기본 통화
      "tags": {},                        // 필수: 빈 딕셔너리
      "additional_info": {},             // 필수: 빈 딕셔너리
      "data": {}                         // 필수: 빈 딕셔너리
    }
  ]
}
```

### 계층별 에러 처리 패턴

#### 1. Service Layer (main.py)
```python
@app.route("Cost.get_data")
def cost_get_data(params: dict) -> Generator[dict, None, None]:
    try:
        # 파라미터 검증
        if not params:
            raise ValueError("Parameters are required")
        
        # 비즈니스 로직 실행
        result_generator = _cost_get_data_logic(params)
        yield from result_generator
        
    except Exception as e:
        _LOGGER.error(f"[cost_get_data] API endpoint failed: {e}")
        # SpaceONE 표준 에러 응답 생성
        yield create_error_response(str(e))
        raise
```

#### 2. Manager Layer
```python
class CostManager(BaseManager):
    def get_data(self, options: dict, secret_data: dict, task_options: dict) -> Generator[dict, None, None]:
        try:
            # 옵션 검증
            self._validate_options(options)
            
            # 데이터 처리
            for batch in self._process_data_batches():
                yield batch
                
        except ValueError as e:
            # 사용자 입력 오류
            _LOGGER.warning(f"Invalid parameters: {e}")
            yield self._create_empty_response()
            
        except ConnectionError as e:
            # 연결 오류
            _LOGGER.error(f"Connection failed: {e}")
            yield self._create_error_response("Connection failed")
            
        except Exception as e:
            # 예상치 못한 오류
            _LOGGER.error(f"Unexpected error: {e}")
            yield self._create_error_response("Internal error")
```

#### 3. Connector Layer
```python
class BigqueryConnector:
    def read_df_from_bigquery(self, query: str) -> pd.DataFrame:
        try:
            # BigQuery 실행
            return pandas_gbq.read_gbq(query, project_id=self.project_id)
            
        except pandas_gbq.exceptions.GenericGBQException as e:
            # BigQuery 특화 오류
            if "authentication" in str(e).lower():
                raise AuthenticationError(f"BigQuery authentication failed: {e}")
            elif "quota" in str(e).lower():
                raise QuotaExceededError(f"BigQuery quota exceeded: {e}")
            else:
                raise BigQueryError(f"BigQuery error: {e}")
                
        except Exception as e:
            # 일반 오류

```

### 에러 응답 생성 헬퍼

```python
def create_error_response(error_message: str) -> dict:
    """에러 상황에서 SpaceONE 표준 응답 생성"""
    return {
        "results": [{
            "cost": 0.0,
            "usage_quantity": 0.0,
            "provider": "google_cloud",
            "region_code": "unknown",
            "product": "error",
            "usage_type": "error",
            "resource": "error",
            "billed_date": datetime.now().strftime("%Y-%m-%d"),
            "currency": "USD",
            "tags": {"error": error_message},
            "additional_info": {"error_details": error_message},
            "data": {"error": True, "message": error_message}
        }]
    }

def create_empty_response() -> dict:
    """빈 결과에 대한 SpaceONE 표준 응답 생성"""
    return {"results": []}
```

## 🚨 자주 발생하는 문제 및 해결

### 1. SpaceONE 응답 오류

#### 문제: data 필드 누락
```python
# ❌ 잘못된 방법
record = {
    "cost": 10.5,
    "provider": "google_cloud"
    # data 필드 누락
}

# ✅ 올바른 방법
record = {
    "cost": 10.5,
    "provider": "google_cloud",
    "data": {}  # 필수 필드 보장
}

# 또는 헬퍼 함수 사용
if "data" not in record or not isinstance(record["data"], dict):
    record["data"] = self._create_spaceone_billing_data(record)
```

#### 문제: JSON 직렬화 오류
```python
# ❌ 문제: Pandas/NumPy 객체 직렬화 실패
record["cost"] = np.float64(10.5)  # JSON 직렬화 불가

# ✅ 해결: 직렬화 전 타입 변환
record["cost"] = float(record["cost"])  # Python 기본 타입으로 변환

# 또는 헬퍼 함수 사용
sanitized_record = self._sanitize_for_serialization(record)
```

#### 문제: 날짜 형식 오류
```python
# ❌ 문제: billed_date 형식 불일치
record["billed_date"] = None

# ✅ 해결: 강제 형식 보장
if not record.get("billed_date"):
    record["billed_date"] = datetime.now().strftime("%Y-%m-%d")
```

# 동적 배치 크기 조정
def calculate_optimal_batch_size(record_size: int) -> int:
    max_message_size = 3 * 1024 * 1024  # 3MB
    optimal_size = max_message_size // (record_size + 100)  # 100바이트 오버헤드
    return max(10, min(optimal_size, 200))  # 10-200 범위
