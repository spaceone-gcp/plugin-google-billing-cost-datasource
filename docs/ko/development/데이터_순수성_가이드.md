#  ABSOLUTE PERFECT ULTRA PURE DATA 가이드

## 개요

이 문서는 SpaceONE Google Cloud Billing Cost Datasource 플러그인에서 **절대적으로 순수한 데이터 처리**를 위한 완전한 가이드입니다. 모든 개발자는 이 원칙을 반드시 준수해야 합니다.

##  ABSOLUTE PERFECT ULTRA PURE DATA 정의

### 핵심 원칙
**"원본 데이터를 절대적으로 변경하지 않고 그대로 보존하는 것"**

-  **NULL 값 보존**: NULL은 NULL로 유지
-  **과학적 표기법 보존**: `9.6e-05`는 문자열로 보존
-  **원본 타입 유지**: 숫자는 숫자로, 문자열은 문자열로
-  **극소값 보존**: `0.000001` 같은 극소값도 그대로 보존
-  **기본값 변환 금지**: NULL을 0.0으로 변환 금지
-  **반올림 금지**: `round()` 함수 사용 금지
-  **타입 변환 금지**: 불필요한 `float()`, `Decimal()` 변환 금지

##  절대 금지 사항

### 1. IFNULL 사용 금지
```sql
--  절대 금지
IFNULL(cost, 0.0) as cost
IFNULL(usage.amount, 0) as usage_amount
IFNULL(location.region, 'global') as region_code

--  올바른 방법
cost as cost  -- NULL 그대로 보존
usage.amount as usage_amount  -- NULL 그대로 보존
location.region as region_code  -- NULL 그대로 보존
```

### 2. 기본값 설정 금지
```python
#  절대 금지
cost = getattr(row, "cost", 0.0)
usage_quantity = getattr(row, "usage_quantity", 0.0)
currency_conversion_rate = getattr(row, "currency_conversion_rate", 1.0)

#  올바른 방법
cost = getattr(row, "cost", None)
usage_quantity = getattr(row, "usage_quantity", None)
currency_conversion_rate = getattr(row, "currency_conversion_rate", None)
```

### 3. 반올림/변환 금지
```python
#  절대 금지
rounded_cost = round(cost, 6)
float_value = float(scientific_notation)
decimal_value = Decimal(str(cost))

#  올바른 방법
cost = cost  # 원본 그대로
scientific_notation = scientific_notation  # 문자열로 보존
original_value = original_value  # 타입 그대로
```

##  올바른 데이터 처리 패턴

### 1. NULL 값 처리
```python
def process_nullable_field(value):
    """NULL 값을 그대로 보존하는 올바른 처리"""
    if value is None:
        return None  # NULL 그대로 반환
    return value  # 원본 값 그대로 반환
```

### 2. 과학적 표기법 처리
```python
def process_scientific_notation(value):
    """과학적 표기법을 문자열로 보존"""

    #  올바른 방법
    return value  # 원본 그대로 (문자열 "9.6e-05" 보존)
```

### 3. 숫자 처리
```python
def process_numeric_field(value):
    """숫자 필드의 순수 처리"""
    if value is None:
        return None  # NULL 보존
    
    #  잘못된 방법
    # if abs(value) < 0.000001:
    #     return 0.0
    # return round(value, 6)
    
    #  올바른 방법
    return value  # 극소값도 원본 그대로 보존
```

### 4. 수학 연산
```python
def safe_math_operation(operation: str, left_value, right_value):
    """순수 데이터를 유지하는 수학 연산"""
    if left_value is None or right_value is None:
        return None
    
    if operation == 'divide':
        if right_value == 0:
            return None
        #  원본 타입으로 나눗셈

    elif operation == 'add':
        #  원본 타입으로 덧셈
        return left_value + right_value
    # ... 다른 연산도 동일
```

##  순수성 달성 지표

### 완벽한 순수성 달성 기준
-  **IFNULL 사용**: 0개
-  **기본값 0.0 설정**: 0개 (비금액 필드 제외)
-  **round() 함수**: 0개
-  **float() 변환**: 0개 (필수적인 경우 제외)
-  **Decimal() 변환**: 0개
-  **NULL 값 보존**: 100%
-  **과학적 표기법 보존**: 100%

### 검증 스크립트
```bash

# scripts/verify_data_purity.sh

echo " ABSOLUTE PERFECT ULTRA PURE DATA 검증 시작..."

# IFNULL 검사

echo "IFNULL 사용: $ifnull_count개 (목표: 0개)"

if [ $ifnull_count -eq 0 ] && [ $default_zero_count -eq 0 ] && [ $round_count -eq 0 ]; then
    echo " ABSOLUTE PERFECT ULTRA PURE DATA 달성!"
else
    echo " 순수성 위반 발견. 수정 필요."
fi
```

##  결론

**ABSOLUTE PERFECT ULTRA PURE DATA**는 단순한 코딩 규칙이 아닌, 데이터의 무결성과 신뢰성을 보장하는 핵심 원칙입니다.

### 핵심 메시지
-  **원본 데이터는 신성하다**: 어떠한 변경도 허용하지 않음
-  **NULL은 의미가 있다**: NULL을 0으로 바꾸는 것은 데이터 왜곡
-  **순수함이 완벽함이다**: 100% 순수한 데이터만이 신뢰할 수 있는 분석 결과를 만듦

이 가이드를 준수함으로써 SpaceONE 플랫폼에서 가장 신뢰할 수 있는 Google Cloud Billing 데이터를 제공할 수 있습니다.
