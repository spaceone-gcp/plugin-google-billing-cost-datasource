# 🚀 SpaceONE 플러그인 서버 실행 체크리스트

이 문서는 SpaceONE Google Cloud Billing 플러그인 서버를 안전하고 효율적으로 실행하기 위한 필수 체크리스트입니다.

## 📋 필수 사전 체크리스트

### 1. 포트 상태 확인 및 정리 (🔴 필수)

**🎯 프로젝트 포트 정책**
- **현재 프로젝트 전용 포트**: `50051`
- **정책**: 50051 포트만 확인하고 정리하며, 다른 포트는 현재 프로젝트에 영향이 없으면 건드리지 않음
- **이유**: 시스템의 다른 서비스들과의 충돌을 방지하고 필요한 부분만 관리

**서버 실행 전 반드시 수행해야 하는 작업**

```bash
# 1. 현재 프로젝트 포트(50051)만 확인
lsof -i :50051

# 2. 50051 포트를 사용하는 프로세스가 있는 경우에만 정리
# ⚠️ 주의: 다른 포트(예: 8080, 3000 등)는 건드리지 않음
if lsof -i :50051 > /dev/null 2>&1; then
    echo "50051 포트 사용 중인 프로세스 발견, 정리 중..."
    kill -9 $(lsof -ti :50051)
else
    echo "50051 포트 사용 가능"
fi

# 3. 정리 후 재확인 (50051 포트만)
lsof -i :50051  # 아무것도 출력되지 않아야 함
```


## 🛠️ 자동화된 서버 관리

### server_manager.sh 사용 (권장)

모든 체크리스트 항목을 자동으로 처리하는 통합 스크립트를 제공합니다:

```bash
# 서버 시작 (모든 체크리스트 자동 수행)
./server_manager.sh start

# 서버 상태 확인
./server_manager.sh status

# 서버 중지
./server_manager.sh stop

# 서버 재시작
./server_manager.sh restart

# 테스트 실행
./server_manager.sh test

# 포트만 정리
./server_manager.sh cleanup
```

### 수동 서버 실행 (고급 사용자)

자동화 스크립트를 사용하지 않는 경우, 다음 순서를 **반드시** 준수하세요:

```bash
# 1. 포트 정리 (50051 포트만 - 필수!)
# ⚠️ 다른 포트는 건드리지 않음
if lsof -i :50051 > /dev/null 2>&1; then
    kill -9 $(lsof -ti :50051)
    echo "50051 포트 정리 완료"
fi

# 2. 환경 확인
cd /Users/mz01-sts/IdeaProjects/plugin-google-billing-cost-datasource
source .venv/bin/activate

# 3. 서버 실행
python test_server.py

# 또는 백그라운드 실행
nohup python test_server.py > server.log 2>&1 &
```

## ⚠️ 문제 해결

### 포트 충돌 문제

**증상**: `bind: address already in use` 오류
**해결책**:
```bash
# 1. 현재 프로젝트 포트(50051)만 확인
lsof -i :50051

# 2. 50051 포트 사용 프로세스만 종료 (다른 포트는 건드리지 않음)
./server_manager.sh cleanup  # 또는 수동으로:
# kill -9 $(lsof -ti :50051)

# 3. 재시작
./server_manager.sh start
```

**🎯 포트 정책 준수사항**:
- 시스템의 다른 포트(8080, 3000, 5432 등)는 건드리지 않음
- 오직 현재 프로젝트의 50051 포트만 관리
- 다른 개발 환경이나 서비스와의 충돌 방지

### 설정 파일 문제

**증상**: `KeyError: 'SERVICE'` 또는 `KeyError: 'PORT'` 오류
**해결책**:
```bash
# 1. 설정 파일 존재 확인
ls -la config.yaml

# 2. 설정 파일 내용 확인
cat config.yaml | grep -E "(SERVICE|PORT)"

# 3. test_server.py 사용 (설정 문제 우회)
python test_server.py
```

### Import 오류

**증상**: `ModuleNotFoundError: No module named 'plugin'`
**해결책**:
```bash
# 1. Python 경로 확인
echo $PYTHONPATH

# 2. 가상환경 재활성화
deactivate
source .venv/bin/activate

# 3. 올바른 디렉토리에서 실행
cd /Users/mz01-sts/IdeaProjects/plugin-google-billing-cost-datasource
python test_server.py
```
