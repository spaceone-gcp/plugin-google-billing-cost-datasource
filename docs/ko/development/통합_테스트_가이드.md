## 🚀 테스트 방법 (3가지)

### 1. Python 스크립트 테스트 (권장)
- **파일**: `test/local_integration_test.py`
- **장점**: 상세한 로그, 결과 분석, 에러 핸들링
- **적합한 경우**: 개발/디버깅, 상세 분석 필요시

### 2. gRPC 스크립트 테스트
- **파일**: `test/grpc_integration_test.sh`
- **장점**: 실제 gRPC API 호출, 운영 환경과 동일
- **적합한 경우**: 통합 테스트, API 호출 검증

### 3. grpcurl 직접 테스트
- **도구**: `grpcurl` 명령어
- **장점**: 수동 제어, 특정 시나리오 테스트
- **적합한 경우**: 특정 API 검증, 문제 재현

## 📊 BigQuery 쿼리 실행 순서 및 로깅

### 총 예상 쿼리 실행 횟수: **5번**

#### **QUERY #0: get_linked_accounts (선택적)**
- **실행 위치**: `CostManager.get_linked_accounts()`
- **목적**: 링크된 계정(프로젝트) 목록 조회
- **SQL**: `SELECT distinct project.id, project.name as project_name FROM ...`
- **로그 패턴**:
```
================================================================================
🔍 [QUERY #0] CostManager - 링크된 계정(프로젝트) 목록 조회
[get_linked_accounts] Query: SELECT distinct project.id, project.name as project_name FROM ...
================================================================================
```

#### **QUERY #1: Job.get_tasks**
- **실행 위치**: `JobManager._create_google_sql()`
- **목적**: 활성 프로젝트 목록 조회 (비용이 있는 프로젝트만)
- **SQL**: `SELECT distinct project.id FROM ... WHERE cost > 0`
- **로그 패턴**:
```
================================================================================
🔍 [QUERY #1] JobManager - 활성 프로젝트 목록 조회
[JobManager] Query: SELECT distinct project.id FROM ...
================================================================================
```

#### **QUERY #2-5: Cost.get_data (프로젝트별)**
- **실행 위치**: `CostManager._create_google_sql()`
- **목적**: 프로젝트별 비용 데이터 조회
- **로그 패턴**:
```
================================================================================
🔍 [QUERY #2-5] CostManager - 프로젝트별 비용 데이터 조회
[BigQuery] 대상 프로젝트: project-name
[BigQuery] 조회 범위: 2024-09
================================================================================
```

## 🎯 Credits Detail 기능 가이드

### **개요**
SpaceONE Google Cloud Cost Analysis Plugin의 **Credits Detail 기능**을 통합 제공합니다.

#### **문제 상황**
- 기존 `Cost.get_data` API: GROUP BY 집계로 최적화되어 있지만 Credits Detail 정보 손실
- Credits Total Amount는 정확하지만, 개별 크레딧의 세부 정보(이름, 타입, 금액)는 빈 배열

#### **해결 방안**
- **기존 API 확장**: `Cost.get_data` API에 Credits Detail 모드 추가
- **SpaceONE 호환성**: 프레임워크 제약으로 인해 기존 API를 확장하는 방식 채택

### **사용법**

#### **기본 사용법**
기존 `Cost.get_data` API에 `task_options.credits_detail_mode = true`를 추가하면 Credits Detail 모드로 실행됩니다.

```json
{
    "options": {
        "source": "bigquery",
        "billing_account_id": "01FD8E-B4DDC1-EAB69F",
        "billing_dataset_id": "multi_region_billing_data",
        "provider": "google_cloud",
        "billing_export_project_id": "your-project"
    },
    "task_options": {
        "credits_detail_mode": true,
        "credits_detail_limit": 50,
        "project_id": "target-project",
        "start": "2024-09"
    }
}
```

#### **옵션 설명**
- `credits_detail_mode`: Credits Detail 모드 활성화 (기본값: false)
- `credits_detail_limit`: 반환할 최대 레코드 수 (기본값: 1000)

### **기능 비교**

| 구분 | 기본 모드 | Credits Detail 모드 |
|------|-----------|-------------------|
| **성능** | 최적화됨 (GROUP BY) | 상대적으로 느림 (원본 데이터) |
| **Credits 정보** | 총액만 | 개별 크레딧 세부 정보 |
| **데이터 크기** | 작음 (집계됨) | 큼 (원본 데이터) |
| **사용 목적** | 일반적인 비용 분석 | 크레딧 상세 분석 |

## 🛠️ 로컬 테스트 환경 설정

### **사전 준비**

#### 1. 환경 설정
```bash
# 가상환경 활성화
source .venv/bin/activate

# 의존성 설치
pip install -r pkg/pip_requirements.txt
```

#### 2. 서비스 계정 키 설정
```bash
# service-account-key.json 파일이 프로젝트 루트에 있는지 확인
ls -la service-account-key.json
```

#### 3. gRPC 서버 실행
```bash
# 터미널 1: 서버 실행
spaceone run plugin

# 또는 직접 실행
python -m spaceone.core.pygrpc.server plugin
```

### **테스트 실행**

#### **방법 1: Python 스크립트 (권장)**
```bash
# 기본 테스트
python test/local_integration_test.py

# 특정 프로젝트 테스트
python test/local_integration_test.py --project-id your-project

# Credits Detail 모드 테스트
python test/local_integration_test.py --credits-detail
```

#### **방법 2: gRPC 스크립트**
```bash
# 통합 테스트 실행
./test/grpc_integration_test.sh

# 특정 모드만 테스트
./test/grpc_integration_test.sh --basic-mode
./test/grpc_integration_test.sh --credits-detail-mode
```

#### **방법 3: grpcurl 직접 호출**
```bash
# 기본 Cost.get_data 호출
grpcurl -plaintext -d '{
    "options": {
        "source": "bigquery",
        "billing_account_id": "01FD8E-B4DDC1-EAB69F",
        "billing_dataset_id": "multi_region_billing_data",
        "provider": "google_cloud",
        "billing_export_project_id": "your-project"
    },
    "secret_data": {...},
    "task_options": {
        "project_id": "target-project",
        "start": "2024-09"
    },
    "domain_id": "domain-id"
}' localhost:50051 spaceone.api.cost_analysis.plugin.Cost.get_data

# Job.get_tasks 호출
grpcurl -plaintext -d '{
    "options": {...},
    "secret_data": {...},
    "task_options": {
        "start": "2024-09"
    },
    "domain_id": "domain-id"
}' localhost:50051 spaceone.api.cost_analysis.plugin.Job.get_tasks
```

## 🔍 grpcurl 테스트 자동화

### **자동화 스크립트 사용**
복잡한 JSON 페이로드와 인증 정보 때문에 직접 `grpcurl` 명령어를 사용하는 것은 번거롭습니다. `test/grpc/test_grpcurl_batch.py` 스크립트를 사용하는 것을 권장합니다.

#### **사전 준비**
1. **gRPC 서버 실행**
   ```bash
   spaceone grpc_server
   ```

2. **grpcurl 설치**
   ```bash
   # macOS (Homebrew)
   brew install grpcurl
   
   # Ubuntu/Debian
   sudo apt-get install grpcurl
   
   # 직접 다운로드
   # https://github.com/fullstorydev/grpcurl/releases
   ```

#### **스크립트 실행**
```bash
# 기본 테스트 (모든 시나리오)
python test/grpc/test_grpcurl_batch.py

# 특정 시나리오만 실행
python test/grpc/test_grpcurl_batch.py --scenario basic
python test/grpc/test_grpcurl_batch.py --scenario credits-detail

# 결과 저장
python test/grpc/test_grpcurl_batch.py --output-dir ./test_results
```

## 📈 성능 및 최적화 가이드

### **BigQuery 최적화**

#### **PARTITIONDATE 활용**
- **자동 범위 확장**: 시작일 -1개월, 종료일 +1개월
- **예시**: `2024-09` 조회 시 → `PARTITIONDATE BETWEEN '2024-08-01' AND '2025-10-31'`
- **효과**: 쿼리 성능 향상 및 비용 절감

#### **프로젝트별 순차 처리**
- **안정성**: 메모리 효율적 처리
- **확장성**: 대용량 데이터 안전 처리
- **모니터링**: 프로젝트별 진행 상황 추적

### **Credits Detail 모드 최적화**
- **제한된 사용**: 필요한 경우에만 활성화
- **적절한 limit 설정**: 기본값 1000, 필요에 따라 조정
- **시간대 분산**: 대용량 조회 시 시간대별 분할 권장

## 🚨 문제 해결 가이드

### **일반적인 문제들**

#### **1. BigQuery 권한 오류**
```
ERROR: 403 Forbidden: Access denied
```
**해결 방법**:
- 서비스 계정에 BigQuery 데이터 뷰어 권한 확인
- 빌링 계정 접근 권한 확인
- 프로젝트 ID 정확성 확인

#### **2. gRPC 연결 오류**
```
ERROR: failed to connect to localhost:50051
```
**해결 방법**:
- gRPC 서버가 실행 중인지 확인
- 포트 50051이 사용 가능한지 확인
- 방화벽 설정 확인

#### **3. 메모리 부족 오류**
```
ERROR: Out of memory
```
**해결 방법**:
- Credits Detail 모드의 limit 값 감소
- 조회 기간을 더 작은 단위로 분할
- 시스템 메모리 확인

### **로그 분석**

#### **성공적인 실행 로그**
```
[SQL 생성] 종료일이 None이므로 현재월로 자동 설정: 2025-09
[PARTITIONDATE 범위] 원본 범위: 2024-09 ~ 2025-09, 확장된 범위: 2024-08-01 ~ 2025-10-31
✅ [BigQuery 커넥터] 쿼리 실행 완료 - 2546행 조회
```

#### **오류 발생 시 로그**
```
[BigQuery] 쿼리 실행 실패: TIMESTAMP +/- INTERVAL is not supported
```
