# 로깅 문제 해결 및 방지 가이드

##  발견된 로깅 문제

### 1. DEBUG 로그가 ERROR 레벨로 출력되는 문제

**문제 상황**: 
```
2025-09-28T07:18:08.467Z [ERROR] a428467e1dc3e69951b91e1663a92bc1 (field_mapper.py:73) [DEBUG] Sample source_data keys: [...]
```

**원인**: 
- `_LOGGER.error()` 메서드를 사용해서 `[DEBUG]` 메시지를 출력
- 실행 중인 디버그 서버 프로세스들이 부적절한 로그 레벨 사용

**해결 방법**:
```python
#  잘못된 방법
_LOGGER.error(f"[DEBUG] 디버그 메시지")

#  올바른 방법  
_LOGGER.debug(f"디버그 메시지")
```

##  로그 모니터링

### 1. 로그 레벨별 카운트 확인
```python
import logging
from collections import Counter

class LogLevelCounter(logging.Handler):
    def __init__(self):
        super().__init__()
        self.counts = Counter()
    
    def emit(self, record):
        self.counts[record.levelname] += 1
    
    def get_stats(self):
        return dict(self.counts)

# 사용 예시
counter = LogLevelCounter()
logging.getLogger("spaceone").addHandler(counter)

# 나중에 통계 확인
print(counter.get_stats())
```

### 2. 부적절한 로그 감지
```python
import re

class LogPatternValidator(logging.Handler):
    def __init__(self):
        super().__init__()
        self.debug_in_error_pattern = re.compile(r'\[DEBUG\]')
    
    def emit(self, record):
        if record.levelname == 'ERROR' and self.debug_in_error_pattern.search(record.getMessage()):
            print(f" ERROR 레벨에서 DEBUG 메시지 감지: {record.getMessage()}")
```
