## 1. 개요

### 1.1. v2.0 주요 혁신사항
- **통합 Source 파라미터**: 모든 데이터 소스를 단일 `source` 설정으로 통합
- **Credits Detail 기능**: 완전한 크레딧 세부 정보 제공
- **GCS 직접 연동**: 새로운 데이터 소스 추가
- **Cost 필드 100% 보장**: 5단계 보장 시스템
- **gRPC 최적화**: 대용량 데이터 안정 전송

### 1.2. 마이그레이션 필요성
- **설정 단순화**: 복잡한 `data_source_type` 설정을 간단한 `source`로 통합
- **성능 향상**: gRPC 청킹 최적화로 대용량 데이터 처리 개선
- **데이터 무결성**: Cost 필드 누락 문제 완전 해결
- **기능 확장**: Credits Detail로 상세한 크레딧 분석 가능

## 2. 주요 변경사항

### 2.1. Breaking Changes ⚠️

#### 2.1.1. 설정 파라미터 변경
```yaml
# v1.x (기존 방식)
options:
  data_source_type: "http_file"  # ❌ 제거됨
  bucket_name: "billing-bucket"
  
# v2.0 (새로운 방식)
options:
  source: "gcs"                  # ✅ 통합 파라미터
  bucket_name: "billing-bucket"
```

#### 2.1.2. 응답 구조 개선
```json
// v1.x: Cost 필드 누락 가능성
{
  "usage_quantity": 0.000004846,
  "additional_info": {...}
  // cost 필드 누락 위험
}

// v2.0: Cost 필드 100% 보장
{
  "cost": 1.826758,              // ✅ 항상 존재
  "usage_quantity": 4.846e-06,   // ✅ 과학적 표기법 지원
  "additional_info": {...},
  "processing_metadata": {       // ✅ 새로운 메타데이터
    "cost_guaranteed": true,
    "version": "v2.0"
  }
}
```

### 2.2. 새로운 기능 🆕

#### 2.2.1. Credits Detail 모드
```yaml
# BigQuery에서 Credits Detail 활성화
options:
  source: "bigquery"
  credits_detail_mode: true      # ✅ 새로운 기능
```

#### 2.2.2. GCS 직접 연동
```yaml
# 새로운 GCS 데이터 소스
options:
  source: "gcs"                  # ✅ 새로운 소스 타입
  bucket_name: "billing-bucket"
  file_pattern: "billing_*.csv"
```

## 4. 설정 마이그레이션

### 4.1. BigQuery 모드 마이그레이션

#### 4.1.1. 기본 설정 변환
```yaml
# Before (v1.x)
options:
  billing_export_project_id: "my-project"
  billing_dataset_id: "billing_export"
  billing_account_id: "123456-789012-345678"

# After (v2.0) - 권장 방식
options:
  source: "bigquery"                        # ✅ 명시적 소스 지정
  billing_export_project_id: "my-project"
  billing_dataset_id: "billing_export"
  billing_account_id: "123456-789012-345678"
  provider: "google_cloud"                  # ✅ 명시적 프로바이더
```

#### 4.1.2. Credits Detail 활성화 (선택)
```yaml
# v2.0 새로운 기능 활용
options:
  source: "bigquery"
  billing_export_project_id: "my-project"
  billing_dataset_id: "billing_export"
  billing_account_id: "123456-789012-345678"
  credits_detail_mode: true                 # ✅ Credits Detail 활성화
  provider: "google_cloud"
```

### 4.2. HTTP 파일 모드 마이그레이션

#### 4.2.1. 기존 HTTP 파일 설정
```yaml
# Before (v1.x)
options:
  data_source_type: "http_file"             # ❌ 제거될 예정
  bucket_name: "billing-bucket"
  file_pattern: "billing_*.csv.gz"
  provider: "google_cloud"

# After (v2.0) - HTTP URL 방식
options:
  source: "http"                            # ✅ 새로운 소스 타입
  base_url: "https://storage.googleapis.com/billing-bucket/billing_export.csv.gz"
  provider: "google_cloud"
```

#### 4.2.2. GCS 직접 연동으로 업그레이드 (권장)
```yaml
# v2.0 권장 방식 - GCS 직접 연동
options:
  source: "gcs"                             # ✅ 새로운 GCS 소스
  bucket_name: "billing-bucket"
  file_pattern: "billing_*.csv.gz"
  date_filter_enabled: true                 # ✅ 날짜 기반 필터링
  provider: "google_cloud"
```

### 4.3. Field Mapper 마이그레이션

#### 4.3.1. 기존 매핑 유지
```yaml
# v1.x와 v2.0 모두 동일하게 작동
field_mapper:
  cost: "cost"
  billed_date: "usage_start_time"
  currency: "currency"
  additional_info:
    project_id: "project.id"
    service_description: "service.description"
```

#### 4.3.2. Credits Detail 매핑 추가 (선택)
```yaml
# v2.0에서 Credits Detail 활용
field_mapper:
  cost: "cost"
  billed_date: "usage_start_time"
  currency: "currency"
  additional_info:
    project_id: "project.id"
    service_description: "service.description"
    credits_detail: "credits"               # ✅ Credits Detail 매핑
```

## 5. 기능별 마이그레이션

### 5.1. BigQuery → BigQuery (Credits Detail 추가)

#### 5.1.1. 단계별 마이그레이션
1. **현재 설정 백업**
   ```bash
   # 현재 DataSource 설정 백업
   spacectl get data-source <data-source-id> > backup_v1_config.yaml
   ```

2. **v2.0 설정으로 업데이트**
   ```yaml
   options:
     source: "bigquery"                     # ✅ 추가
     credits_detail_mode: false             # ✅ 기본값 (기존 동작 유지)
     billing_export_project_id: "my-project"
     billing_dataset_id: "billing_export"
     billing_account_id: "123456-789012-345678"
     provider: "google_cloud"               # ✅ 추가
   ```

3. **점진적 Credits Detail 활성화**
   ```yaml
   # 테스트 후 활성화
   options:
     source: "bigquery"
     credits_detail_mode: true              # ✅ Credits Detail 활성화
     # ... 나머지 설정 동일
   ```

### 5.2. HTTP 파일 → GCS 직접 연동

#### 5.2.1. 권한 확인
```bash
# GCS 버킷 접근 권한 확인
gsutil ls gs://your-billing-bucket/

# Service Account 권한 확인
gcloud projects get-iam-policy YOUR_PROJECT_ID \
  --flatten="bindings[].members" \
  --filter="bindings.members:serviceAccount:YOUR_SA_EMAIL"
```

#### 5.2.2. 설정 변환
```yaml
# Before: HTTP 파일 모드
options:
  data_source_type: "http_file"
  bucket_name: "billing-bucket"
  file_pattern: "billing_*.csv.gz"

# After: GCS 직접 연동
options:
  source: "gcs"
  bucket_name: "billing-bucket"
  file_pattern: "billing_*.csv.gz"
  date_filter_enabled: true                 # ✅ 성능 최적화
```

### 5.3. 새로운 기능 활용

#### 5.3.1. Credits Detail 분석
```yaml
# Credits Detail 모드 설정
task_options:
  start: "2024-09"
  credits_detail_mode: true                 # ✅ 상세 크레딧 정보
```

#### 5.3.2. 성능 최적화 설정
```yaml
# gRPC 청킹 최적화 (자동)
options:
  source: "bigquery"
  # gRPC 배치 크기는 자동 조정됨 (기본값: 5)
```

## 7. 문제 해결

### 7.1. 일반적인 마이그레이션 이슈

#### 7.1.1. "source 파라미터 누락" 오류
```
ERROR_REQUIRED_PARAMETER: source parameter is required
```

**해결방법**:
```yaml
# source 파라미터 추가
options:
  source: "bigquery"  # 또는 "gcs", "http"
  # ... 나머지 설정
```

#### 7.1.2. "data_source_type은 더 이상 지원되지 않음" 경고
```
DEPRECATED: data_source_type parameter is deprecated, use 'source' instead
```

**해결방법**:
```yaml
# Before
options:
  data_source_type: "http_file"  # ❌ 제거

# After  
options:
  source: "http"                 # ✅ 새로운 방식
```

#### 7.1.3. Cost 필드 누락 (v1.x에서 발생했던 문제)
```
Missing 'cost' field in response
```

**v2.0에서는 자동 해결**:
- 5단계 보장 시스템으로 100% 해결
- 과학적 표기법도 완벽 지원
- 추가 설정 불필요

### 7.2. Credits Detail 관련 이슈

#### 7.2.1. Credits Detail 데이터 없음
```yaml
# 확인사항
options:
  source: "bigquery"
  credits_detail_mode: true      # ✅ 활성화 확인
  
task_options:
  start: "2024-09"               # ✅ 크레딧이 있는 기간 설정
```

#### 7.2.2. gRPC 메시지 크기 오류 (v1.x 문제)
```
ResourceExhausted: grpc: received message larger than max
```

**v2.0에서는 자동 해결**:
- 스마트 청킹 시스템으로 자동 배치 조정
- 배치 크기 5로 최적화
- 추가 설정 불필요

### 7.3. 성능 최적화 팁

#### 7.3.1. GCS 연동 최적화
```yaml
options:
  source: "gcs"
  bucket_name: "billing-bucket"
  file_pattern: "billing_2024*.csv.gz"     # ✅ 구체적인 패턴
  date_filter_enabled: true                # ✅ 날짜 필터링 활성화
```

#### 7.3.2. BigQuery 최적화
```yaml
options:
  source: "bigquery"
  credits_detail_mode: false               # ✅ 불필요시 비활성화
  
task_options:
  start: "2024-09"                         # ✅ 구체적인 기간 설정
```
