# 가격 책정 데이터 내보내기의 구조

이 문서는 Google Cloud의 공식 [가격 책정 데이터 내보내기의 구조](https://cloud.google.com/billing/docs/how-to/export-data-bigquery-tables/pricing-data?hl=ko) 가이드를 기반으로, 가격 데이터의 상세한 스키마와 이를 활용한 비용 분석 방법을 설명합니다.

## 📋 개요

**가격 데이터 내보내기**는 Google Cloud의 모든 서비스와 SKU에 대한 공개 정가 정보를 BigQuery로 내보내는 기능입니다. 이를 통해 실제 청구 데이터와 별도로 가격 정보를 분석하고, 비용 예측 및 최적화를 위한 인사이트를 얻을 수 있습니다.

### 테이블 정보
- **테이블명**: `cloud_pricing_export`
- **생성 조건**: 가격 데이터 내보내기 활성화
- **업데이트 주기**: 가격 변동 시 일 1회
- **데이터 범위**: 모든 Google Cloud 서비스의 공개 정가
- **파티셔닝**: `_PARTITIONTIME` 필드로 일 단위 파티셔닝

## 🆚 청구 데이터와 가격 데이터 비교

| 구분 | 청구 데이터 | 가격 데이터 |
|:---|:---|:---|
| **데이터 유형** | 실제 사용량 및 청구 데이터 | 서비스별 정가 정보 |
| **테이블명** | `gcp_billing_export_*` | `cloud_pricing_export` |
| **업데이트 주기** | 일 1-2회 (사용량 기반) | 일 1회 (가격 변동 시) |
| **데이터 범위** | 특정 청구 계정의 실제 비용 | 모든 GCP 서비스의 공개 정가 |
| **주요 용도** | 실제 비용 추적 및 분석 | 가격 비교 및 예산 계획 |

## 📊 가격 데이터 스키마

### 1. 기본 식별 정보

| 필드명 | 타입 | 설명 | 활용 예시 |
|:---|:---|:---|:---|
| `export_time` | `TIMESTAMP` | 데이터 내보내기 처리 시간 | 데이터 신선도 확인 |
| `pricing_as_of_time` | `TIMESTAMP` | 가격 데이터 생성 일시 | 가격 변동 시점 추적 |
| `billing_account_id` | `STRING` | 청구 계정 ID | 계정별 할인 가격 확인 |

```sql
-- 최신 가격 데이터 확인
SELECT 
  DATE(pricing_as_of_time) as pricing_date,
  COUNT(*) as total_skus,
  COUNT(DISTINCT service.id) as unique_services
FROM `project.dataset.cloud_pricing_export`
WHERE DATE(_PARTITIONTIME) = (
  SELECT MAX(DATE(_PARTITIONTIME)) 
  FROM `project.dataset.cloud_pricing_export`
)
GROUP BY pricing_date
ORDER BY pricing_date DESC;
```

### 2. 서비스 및 SKU 정보

| 필드명 | 타입 | 설명 | 활용 예시 |
|:---|:---|:---|:---|
| `service.id` | `STRING` | Google Cloud 서비스 ID | 서비스별 가격 분석 |
| `service.description` | `STRING` | 서비스 설명 | 사용자 친화적 보고서 |
| `sku.id` | `STRING` | SKU ID | 정확한 가격 매핑 |
| `sku.description` | `STRING` | SKU 설명 | 상세 가격 분석 |

```sql
-- Compute Engine 서비스의 모든 SKU 가격 조회
SELECT 
  sku.id,
  sku.description,
  service.description as service_name
FROM `project.dataset.cloud_pricing_export`
WHERE DATE(_PARTITIONTIME) = CURRENT_DATE() - 1
  AND service.description = 'Compute Engine'
ORDER BY sku.description;
```

### 3. 제품 분류 정보 (베타)

| 필드명 | 타입 | 설명 | 활용 예시 |
|:---|:---|:---|:---|
| `product_taxonomy` | `RECORD` | 제품 분류 정보 | 제품군별 가격 분석 |
| `product_taxonomy.type` | `STRING` | 제품 유형 | 리소스 타입별 분류 |
| `product_taxonomy.resource` | `STRING` | 리소스 분류 | 리소스별 가격 비교 |

```sql
-- 제품 분류별 가격 분포 분석
SELECT 
  product_taxonomy.type as product_type,
  product_taxonomy.resource as resource_type,
  COUNT(*) as sku_count,
  COUNT(DISTINCT service.description) as service_count
FROM `project.dataset.cloud_pricing_export`
WHERE DATE(_PARTITIONTIME) = CURRENT_DATE() - 1
  AND product_taxonomy.type IS NOT NULL
GROUP BY product_type, resource_type
ORDER BY sku_count DESC;
```

### 4. 지역 분류 정보 (베타)

| 필드명 | 타입 | 설명 | 활용 예시 |
|:---|:---|:---|:---|
| `geo_taxonomy` | `RECORD` | 지역 분류 정보 | 지역별 가격 분석 |
| `geo_taxonomy.type` | `STRING` | 지역 유형 | 지역 타입별 분류 |
| `geo_taxonomy.region` | `STRING` | 리전 정보 | 리전별 가격 비교 |

```sql
-- 리전별 Compute Engine 인스턴스 가격 비교
SELECT 
  geo_taxonomy.region,
  sku.description,
  tier.usd_amount as price_per_hour
FROM `project.dataset.cloud_pricing_export`,
     UNNEST(list_price.tiered_rates) as tier
WHERE DATE(_PARTITIONTIME) = CURRENT_DATE() - 1
  AND service.description = 'Compute Engine'
  AND sku.description LIKE '%Instance Core%'
  AND tier.start_usage_amount = 0
  AND geo_taxonomy.region IS NOT NULL
ORDER BY geo_taxonomy.region, sku.description;
```

### 5. 공개 정가 정보 (List Price)

| 필드명 | 타입 | 설명 | 활용 예시 |
|:---|:---|:---|:---|
| `list_price` | `RECORD` | 공개 정가 정보 | 표준 가격 분석 |
| `list_price.aggregation_info` | `RECORD` | 집계 정보 | 가격 책정 방식 이해 |
| `list_price.tiered_rates` | `RECORD` (반복) | 계층별 요금제 | 사용량별 가격 계산 |

#### 집계 정보 (Aggregation Info)

| 필드명 | 타입 | 설명 |
|:---|:---|:---|
| `aggregation_info.aggregation_level` | `STRING` | 집계 수준 (ACCOUNT, PROJECT 등) |
| `aggregation_info.aggregation_interval` | `STRING` | 집계 간격 (DAILY, MONTHLY 등) |
| `aggregation_info.aggregation_count` | `INTEGER` | 집계 개수 |

#### 계층별 요금제 (Tiered Rates)

| 필드명 | 타입 | 설명 | 활용 예시 |
|:---|:---|:---|:---|
| `tiered_rates.pricing_unit_quantity` | `FLOAT` | 가격 책정 단위 수량 | 단위 가격 계산 |
| `tiered_rates.start_usage_amount` | `FLOAT` | 해당 계층 시작 사용량 | 계층별 가격 적용 |
| `tiered_rates.usd_amount` | `FLOAT` | USD 기준 단위 가격 | 표준 가격 비교 |
| `tiered_rates.account_currency_amount` | `FLOAT` | 계정 통화 기준 단위 가격 | 계정별 가격 |

```sql
-- Cloud Storage 계층별 요금제 분석
SELECT 
  sku.description,
  tier.pricing_unit_quantity,
  tier.start_usage_amount,
  tier.usd_amount,
  CASE 
    WHEN tier.start_usage_amount = 0 THEN 'First Tier'
    WHEN tier.start_usage_amount < 1000000000 THEN 'Second Tier'
    ELSE 'Higher Tier'
  END as price_tier
FROM `project.dataset.cloud_pricing_export`,
     UNNEST(list_price.tiered_rates) as tier
WHERE DATE(_PARTITIONTIME) = CURRENT_DATE() - 1
  AND service.description = 'Cloud Storage'
  AND sku.description LIKE '%Storage%'
ORDER BY sku.description, tier.start_usage_amount;
```

### 6. 계정별 할인 가격 (Billing Account Price)

| 필드명 | 타입 | 설명 | 활용 예시 |
|:---|:---|:---|:---|
| `billing_account_price` | `RECORD` | 청구 계정별 할인 적용 가격 | 계약 할인 분석 |
| `billing_account_price.aggregation_info` | `RECORD` | 집계 정보 | 할인 적용 방식 |
| `billing_account_price.tiered_rates` | `RECORD` (반복) | 할인 적용 계층별 요금 | 실제 지불 가격 |

```sql
-- 정가 vs 계정별 할인 가격 비교
SELECT 
  service.description,
  sku.description,
  list_tier.usd_amount as list_price,
  account_tier.usd_amount as account_price,
  ROUND((1 - account_tier.usd_amount / NULLIF(list_tier.usd_amount, 0)) * 100, 2) as discount_percentage
FROM `project.dataset.cloud_pricing_export`,
     UNNEST(list_price.tiered_rates) as list_tier,
     UNNEST(billing_account_price.tiered_rates) as account_tier
WHERE DATE(_PARTITIONTIME) = CURRENT_DATE() - 1
  AND billing_account_id = 'YOUR_BILLING_ACCOUNT_ID'
  AND list_tier.start_usage_amount = account_tier.start_usage_amount
  AND list_tier.start_usage_amount = 0
  AND account_tier.usd_amount < list_tier.usd_amount
ORDER BY discount_percentage DESC;
```

## 🔍 가격 데이터 활용 사례

### 1. 서비스별 가격 비교

```sql
-- 컴퓨팅 서비스 간 시간당 비용 비교
SELECT 
  service.description as service_name,
  sku.description as resource_type,
  tier.usd_amount as hourly_cost_usd,
  geo_taxonomy.region
FROM `project.dataset.cloud_pricing_export`,
     UNNEST(list_price.tiered_rates) as tier
WHERE DATE(_PARTITIONTIME) = CURRENT_DATE() - 1
  AND service.description IN ('Compute Engine', 'App Engine', 'Cloud Run')
  AND sku.description LIKE '%CPU%'
  AND tier.start_usage_amount = 0
  AND geo_taxonomy.region = 'us-central1'
ORDER BY hourly_cost_usd;
```

### 2. 지역별 가격 차이 분석

```sql
-- 리전별 Compute Engine 가격 차이 분석
WITH regional_prices AS (
  SELECT 
    geo_taxonomy.region,
    sku.description,
    tier.usd_amount as price
  FROM `project.dataset.cloud_pricing_export`,
       UNNEST(list_price.tiered_rates) as tier
  WHERE DATE(_PARTITIONTIME) = CURRENT_DATE() - 1
    AND service.description = 'Compute Engine'
    AND sku.description = 'N1 Standard Instance Core running in Americas'
    AND tier.start_usage_amount = 0
    AND geo_taxonomy.region IS NOT NULL
),
price_comparison AS (
  SELECT 
    region,
    price,
    price - MIN(price) OVER() as price_diff,
    ROUND((price - MIN(price) OVER()) / MIN(price) OVER() * 100, 2) as price_premium_pct
  FROM regional_prices
)
SELECT *
FROM price_comparison
ORDER BY price_premium_pct DESC;
```

### 3. 가격 변동 추적

```sql
-- 특정 SKU의 가격 변동 이력
SELECT 
  DATE(_PARTITIONTIME) as price_date,
  sku.description,
  tier.usd_amount as current_price,
  LAG(tier.usd_amount) OVER (ORDER BY DATE(_PARTITIONTIME)) as previous_price,
  ROUND((tier.usd_amount - LAG(tier.usd_amount) OVER (ORDER BY DATE(_PARTITIONTIME))) / 
        NULLIF(LAG(tier.usd_amount) OVER (ORDER BY DATE(_PARTITIONTIME)), 0) * 100, 2) as price_change_pct
FROM `project.dataset.cloud_pricing_export`,
     UNNEST(list_price.tiered_rates) as tier
WHERE sku.id = 'YOUR_SKU_ID'
  AND tier.start_usage_amount = 0
  AND DATE(_PARTITIONTIME) >= DATE_SUB(CURRENT_DATE(), INTERVAL 30 DAY)
ORDER BY price_date DESC;
```

### 4. 비용 예측 및 시나리오 분석

```sql
-- 사용량 증가 시나리오별 예상 비용 계산
WITH usage_scenarios AS (
  SELECT 
    service.description,
    sku.description,
    -- 현재 사용량 기준 (예시)
    1000 as current_usage,
    tier.usd_amount * 1000 as current_cost,
    -- 2배 증가 시나리오
    tier.usd_amount * 2000 as doubled_cost,
    -- 5배 증가 시나리오
    tier.usd_amount * 5000 as five_times_cost,
    -- 10배 증가 시나리오
    tier.usd_amount * 10000 as ten_times_cost
  FROM `project.dataset.cloud_pricing_export`,
       UNNEST(list_price.tiered_rates) as tier
  WHERE DATE(_PARTITIONTIME) = CURRENT_DATE() - 1
    AND service.description IN ('Compute Engine', 'Cloud Storage', 'BigQuery')
    AND tier.start_usage_amount = 0
)
SELECT 
  service.description,
  sku.description,
  current_cost,
  doubled_cost - current_cost as additional_cost_2x,
  five_times_cost - current_cost as additional_cost_5x,
  ten_times_cost - current_cost as additional_cost_10x
FROM usage_scenarios
ORDER BY current_cost DESC;
```

## 📈 실제 청구 데이터와의 연계 분석

### 1. 할인율 계산

```sql
-- 실제 비용과 정가 비교를 통한 할인율 분석
WITH billing_data AS (
  SELECT 
    service.description,
    sku.id,
    SUM(cost) as actual_cost,
    SUM(usage.amount_in_pricing_units) as usage_amount
  FROM `project.billing_export.gcp_billing_export_v1_ACCOUNT_ID`
  WHERE DATE(usage_start_time) = '2024-01-15'
  GROUP BY service.description, sku.id
),
pricing_data AS (
  SELECT 
    service.description,
    sku.id,
    tier.usd_amount as list_price_per_unit
  FROM `project.dataset.cloud_pricing_export`,
       UNNEST(list_price.tiered_rates) as tier
  WHERE DATE(_PARTITIONTIME) = '2024-01-15'
    AND tier.start_usage_amount = 0
)
SELECT 
  b.service.description,
  b.actual_cost,
  (b.usage_amount * p.list_price_per_unit) as list_price_cost,
  ROUND((1 - b.actual_cost / NULLIF(b.usage_amount * p.list_price_per_unit, 0)) * 100, 2) as effective_discount_pct
FROM billing_data b
JOIN pricing_data p 
  ON b.service.description = p.service.description 
  AND b.sku.id = p.sku.id
WHERE (b.usage_amount * p.list_price_per_unit) > 0
ORDER BY effective_discount_pct DESC;
```

### 2. 비용 최적화 기회 식별

```sql
-- 리전 이전을 통한 비용 절감 기회 분석
WITH current_costs AS (
  SELECT 
    project.id,
    service.description,
    sku.id,
    location.region as current_region,
    SUM(cost) as monthly_cost,
    SUM(usage.amount_in_pricing_units) as usage_amount
  FROM `project.billing_export.gcp_billing_export_v1_ACCOUNT_ID`
  WHERE DATE(usage_start_time) >= DATE_SUB(CURRENT_DATE(), INTERVAL 30 DAY)
  GROUP BY project.id, service.description, sku.id, location.region
),
alternative_pricing AS (
  SELECT 
    service.description,
    sku.id,
    geo_taxonomy.region,
    tier.usd_amount as price_per_unit
  FROM `project.dataset.cloud_pricing_export`,
       UNNEST(list_price.tiered_rates) as tier
  WHERE DATE(_PARTITIONTIME) = CURRENT_DATE() - 1
    AND tier.start_usage_amount = 0
    AND geo_taxonomy.region IN ('us-central1', 'us-east1', 'europe-west1', 'asia-east1')
)
SELECT 
  c.project.id,
  c.service.description,
  c.current_region,
  c.monthly_cost as current_monthly_cost,
  a.geo_taxonomy.region as alternative_region,
  (c.usage_amount * a.price_per_unit) as alternative_monthly_cost,
  c.monthly_cost - (c.usage_amount * a.price_per_unit) as potential_savings
FROM current_costs c
JOIN alternative_pricing a
  ON c.service.description = a.service.description
  AND c.sku.id = a.sku.id
WHERE c.current_region != a.geo_taxonomy.region
  AND (c.usage_amount * a.price_per_unit) < c.monthly_cost
ORDER BY potential_savings DESC;
```

## ⚠️ 가격 데이터 사용 시 주의사항

### 1. 데이터 신선도 확인
```sql
-- 가격 데이터의 최신성 확인
SELECT 
  MAX(DATE(_PARTITIONTIME)) as latest_partition,
  MAX(DATE(pricing_as_of_time)) as latest_pricing_date,
  DATE_DIFF(CURRENT_DATE(), MAX(DATE(pricing_as_of_time)), DAY) as days_old
FROM `project.dataset.cloud_pricing_export`;
```

### 2. 계층별 요금제 이해
- **시작 사용량**: `start_usage_amount`는 해당 가격이 적용되는 최소 사용량
- **누적 적용**: 계층별 요금은 누적적으로 적용됨
- **단위 확인**: `pricing_unit_quantity`와 실제 사용량 단위가 일치하는지 확인

### 3. 지역별 가격 차이
- **지역 제한**: 모든 서비스가 모든 지역에서 제공되지 않음
- **가격 변동**: 지역별로 가격이 다르며 시간에 따라 변동 가능
