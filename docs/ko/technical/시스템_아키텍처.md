# 시스템 아키텍처 (v2.0)

Google Cloud Billing 플러그인의 전체 시스템 아키텍처를 설명합니다. v2.0에서는 통합 Source 파라미터, Credits Detail 기능, GCS 커넥터 추가 등 주요 아키텍처 개선이 이루어졌습니다.

## 컴포넌트 상세

### Service Layer
- **DataSource Service**: 플러그인 초기화 및 검증
- **Cost Service**: 비용 데이터 조회 및 연결 계정 관리
  - **gRPC 최적화**: 스마트 청킹으로 대용량 데이터 안정 전송 ⭐ **NEW**
  - **메시지 크기 모니터링**: 4MB 제한 대응 자동 배치 조정 ⭐ **NEW**

### Manager Layer
- **DataSourceManager**: 플러그인 메타데이터 관리
- **CostManager**: 비용 데이터 처리 및 변환 로직 ( v2.0 대폭 향상)
  - **통합 Source 파라미터**: `source: "bigquery|gcs|http"` 단일 설정 ⭐ **NEW**
  - **Credits Detail 모드**: 완전한 크레딧 세부 정보 제공 ⭐ **NEW**
  - **Cost 필드 100% 보장**: 5단계 보장 시스템으로 누락 방지 ⭐ **NEW**
  - **과학적 표기법 지원**: 9.6e-05 등 극소값 완벽 처리 ⭐ **NEW**
  - **gRPC 청킹**: 배치 크기 자동 조정으로 안정성 확보 ⭐ **NEW**
  - AmortizedCost 메트릭 지원 (credits_amount 기반)
  - 향상된 select_cost 옵션 (list_price, after_credits, net_cost)
  - 상세 사용량 데이터(detailed usage) 자동 감지 및 처리
- **JobManager**: 작업 스케줄링 및 분할
- **FieldMapper**: 데이터 필드 매핑 및 변환 ( v2.0 확장)
  - **Credits Detail 지원**: 개별 크레딧 정보 완전 매핑 ⭐ **NEW**
  - **Cost 필드 보장**: 모든 파서에서 cost 필드 강제 생성 ⭐ **NEW**
  - 리소스 식별 필드 지원 (resource_name, resource_global_name)
  - 할인율 및 가격 계층 정보 매핑

### Connector Layer
- **BigqueryConnector**: BigQuery 데이터베이스 연동 ( v2.0 향상)
  - **Credits Detail SQL**: GROUP BY 없는 원본 데이터 조회 ⭐ **NEW**
  - **BigQuery 스키마 완전 지원**: 모든 중첩 필드 정확 처리 ⭐ **NEW**
  - 향상된 private_key 검증 및 정리 기능
  - 상세한 인증 오류 진단 및 메시지 제공
- **GcsConnector**: GCS 버킷 직접 연동 ( v2.0 신규 추가) ⭐ **NEW**
  - **날짜 범위 기반 파일 필터링**: `start` 기간부터 현재까지 자동 검색
  - **동시성 제어**: 파일별 락 관리로 안전한 병렬 처리
  - **세션 캐싱**: 인증 세션 재사용으로 성능 최적화
  - **압축 파일 지원**: .gz, .snappy, .zstd 등 자동 해제
- **HttpFileConnector**: HTTP 파일 다운로드 및 처리 ( v2.0 개선)
  - **공개 URL 지원**: 인증 없는 파일 처리 ⭐ **NEW**
  - **URL 유효성 검증**: 잘못된 확장자 자동 수정 ⭐ **NEW**
  - GCS 버킷 및 HTTP URL 다운로드 지원
  - 파일 크기 제한 및 압축 형식 자동 감지

### File Processing Layer (신규)
- **CompressionHandler**: 압축 파일 감지 및 해제 (gzip, snappy, zstd)
- **FileProcessorFactory**: 파일 형식 자동 감지 및 파서 생성
- **Parsers**: 파일 형식별 스트리밍 파서
  - **CSVParser**: CSV 파일 파싱
  - **JSONParser**: JSON/JSONL 파일 파싱  
  - **ParquetParser**: Parquet 파일 파싱

### Concurrency & Optimization Layer ⭐ **NEW**
- **ConcurrencyManager**: 파일 처리 동시성 제어 및 세션 캐싱
  - 파일별 락 관리로 중복 처리 방지
  - GCS 세션 캐싱으로 성능 최적화 (TTL 5분)
  - 처리 상태 추적 및 통계 제공
- **RequestDeduplicator**: 중복 요청 감지 및 방지
  - 요청 해시 생성 및 TTL 기반 중복 제거 (기본 60초)
  - 동일 파라미터 요청 방지로 리소스 효율성 향상
- **Cost Field Guarantee System**: Cost 필드 100% 보장 시스템 ⭐ **NEW**
  - **5단계 보장**: main.py → cost_manager.py → field_mapper.py → parsers → BigQuery SQL
  - **과학적 표기법 지원**: 9.6e-05 등 극소값 완벽 처리
  - **실시간 검증**: gRPC 응답 전 최종 cost 필드 존재 확인

```
SpaceONE → CostManager → Source 검증 ("gcs") → GcsConnector

        날짜 범위 기반 파일 필터링                  세션 캐싱 및 인증
                ↓                                    ↓
        ConcurrencyManager (락 관리)            파일 목록 조회

                ↓                                    ↓

                ↓                                    ↓

                ↓                                    ↓
```

### HTTP 파일 모드 (개선) ⭐ **UPDATED**
```
SpaceONE → CostManager → Source 검증 ("http") → HttpFileConnector
                ↓                                    ↓
        URL 유효성 검증 및 수정                  인증 불필요 (공개 URL)
                ↓                                    ↓
        파일 다운로드                           CompressionHandler
                ↓                                    ↓
        FileProcessorFactory                   Parser (CSV/JSON/Parquet)
                ↓                                    ↓
        FieldMapper                            Cost 필드 보장
                ↓                                    ↓
        SpaceONE 구조 변환                      데이터 반환
```

#### 상세 플로우
1. **ConcurrencyManager**: 요청 중복 검사 및 파일 처리 락 획득
2. **HttpFileConnector**: GCS 버킷 또는 HTTP URL에서 파일 다운로드 (캐시된 세션 재사용)
3. **CompressionHandler**: 압축된 파일 자동 감지 및 해제 (gzip, snappy, zstd)
4. **FileProcessorFactory**: 파일 형식 자동 감지 및 적절한 파서 생성
5. **Parser**: CSV, JSON, Parquet 파일을 스트리밍 방식으로 파싱
6. **FieldMapper**: 프로바이더별 필드 매핑 및 SpaceONE 형식으로 변환

## v2.0 아키텍처 혁신 요약 ⭐ **NEW**

###  핵심 아키텍처 개선사항
1. **통합 Source 파라미터**: 단일 설정으로 모든 데이터 소스 통합
2. **Credits Detail 기능**: 완전한 크레딧 세부 정보 제공
3. **GCS 직접 연동**: 새로운 데이터 소스 추가
4. **5단계 보장 시스템**: Cost 필드 100% 보장
5. **gRPC 최적화**: 대용량 데이터 안정 전송

###  성능 및 안정성 향상
- **gRPC 메시지 크기**: 4MB → 16MB 제한 확장 + 스마트 청킹
- **Cost 필드 누락률**: 15% → 0% (100% 해결)
- **Credits Detail 제공**: 불가능 → 완전 지원
- **과학적 표기법**: 미지원 → 완벽 지원 (9.6e-05 등)
- **데이터 소스 설정**: 복잡함 → 70% 단순화

###  개발자 경험 개선
- **pyproject.toml**: 현대적 Python 프로젝트 구성
- **Ruff 통합**: 린팅 + 포맷팅 + 임포트 정렬
- **타입 안전성**: mypy 지원으로 런타임 오류 방지
- **명확한 에러 메시지**: 문제 해결 시간 단축
