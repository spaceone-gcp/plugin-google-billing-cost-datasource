# 데이터 모델 정의서 (v2.0)

v2.0에서 사용되는 데이터 모델을 정의합니다. 통합 Source 파라미터, Credits Detail 기능, Cost 필드 보장 시스템을 포함합니다.

## 🚨 데이터 모델 설계 원칙 (v2.0) ⭐ **UPDATED**

### v2.0 핵심 원칙
- **Cost 필드 100% 보장**: 5단계 보장 시스템으로 cost 필드 누락 방지 ⭐ **NEW**
- **과학적 표기법 지원**: 9.6e-05 등 극소값 완벽 처리 ⭐ **NEW**
- **Credits Detail 완전 지원**: 개별 크레딧 정보 손실 없이 제공 ⭐ **NEW**
- **통합 Source 기반**: 단일 source 파라미터로 모든 데이터 소스 통합 ⭐ **NEW**

### ABSOLUTE PERFECT ULTRA PURE DATA 준수
- **스키마 일치성**: 모든 데이터 모델은 BigQuery 스키마와 100% 일치해야 함
- **NULL 값 허용**: 모든 필드는 NULL을 허용하며, 기본값으로 변환하지 않음
- **원본 타입 보존**: 데이터 타입 변환 없이 원본 그대로 보존
- **중첩 구조 지원**: RECORD 타입의 중첩 필드 정확히 매핑

### 필드 매핑 규칙
- **완전 매핑**: BigQuery 스키마의 모든 필드가 응답에 포함되어야 함
- **경로 정확성**: 중첩 필드는 정확한 경로로 매핑 (예: `service.description`)
- **타입 일치**: 스키마의 데이터 타입과 응답 데이터 타입 일치
- **REPEATED 처리**: 배열 필드는 JSON 문자열로 변환

## v2.0 통합 Source 데이터 모델 ⭐ **NEW**

### SourceConfig
```python
from typing import Literal, Optional, Dict, Any
from dataclasses import dataclass

@dataclass
class SourceConfig:
    """통합 Source 설정 모델"""
    source: Literal["bigquery", "gcs", "http"]  # 필수: 데이터 소스 타입
    provider: str = "google_cloud"              # 필수: 프로바이더
    
    # BigQuery 전용 설정
    billing_export_project_id: Optional[str] = None
    billing_dataset_id: Optional[str] = None
    billing_account_id: Optional[str] = None
    credits_detail_mode: bool = False           # ⭐ NEW: Credits Detail 모드
    
    # GCS 전용 설정
    bucket_name: Optional[str] = None
    file_pattern: Optional[str] = None
    date_filter_enabled: bool = True            # ⭐ NEW: 날짜 기반 파일 필터링
    
    # HTTP 전용 설정
    base_url: Optional[str] = None
    authentication_required: bool = False       # ⭐ NEW: 인증 필요 여부
    
    # 공통 설정
    field_mapper: Optional[Dict[str, Any]] = None
    default_vars: Optional[Dict[str, Any]] = None
    
    def __post_init__(self):
        """Source별 필수 설정 검증"""
        if self.source == "bigquery":
            required_fields = ["billing_export_project_id", "billing_dataset_id"]
            for field in required_fields:
                if getattr(self, field) is None:
                    raise ValueError(f"BigQuery source requires {field}")
        elif self.source == "gcs":
            if self.bucket_name is None:
                raise ValueError("GCS source requires bucket_name")
        elif self.source == "http":
            if self.base_url is None:
                raise ValueError("HTTP source requires base_url")
```

## SpaceONE 표준 데이터 모델 (v2.0) ⭐ **UPDATED**

**🚨 CRITICAL: v2.0에서는 5단계 보장 시스템으로 cost 필드 100% 보장합니다.**

### CostData (v2.0 Enhanced)
```python
@dataclass
class CostData:
    """SpaceONE 표준 비용 데이터 (v2.0)
    
    v2.0 개선사항:
    - Cost 필드 5단계 보장 시스템
    - 과학적 표기법 완벽 지원 (9.6e-05 등)
    - Credits Detail 완전 지원
    - gRPC 청킹 최적화 대응
    """
    cost: float                            # 🚨 CRITICAL: 최상위 필수 필드, 5단계 보장 시스템으로 100% 보장
    usage_quantity: float = 0.0            # 필수: 사용량 (과학적 표기법 지원)
    provider: str = "google_cloud"         # 필수: 프로바이더
    region_code: str = ""                  # 필수: 리전 코드 (빈 문자열 허용)
    product: str = ""                      # 필수: 제품명
    usage_type: str = ""                   # 필수: 사용 유형
    resource: str = ""                     # 필수: 리소스 식별자
    currency: str = "USD"                  # 필수: 통화 (최상위 필드)
    billed_date: str = None                # 필수: 청구 날짜 (YYYY-MM-DD 형식)
    tags: Dict[str, str] = None            # 필수: 태그 (빈 딕셔너리 허용)
    additional_info: Dict[str, any] = None # 필수: 추가 정보 (Credits Detail 포함)
    data: Dict[str, any] = None            # 필수: SpaceONE 프레임워크 요구사항 (cost, list_price만 포함)
    
    # v2.0 추가 필드 ⭐ **NEW**
    credits_detail: Optional[List[Dict]] = None  # ⭐ NEW: Credits Detail 정보
    source_type: Optional[str] = None            # ⭐ NEW: 데이터 소스 타입 (bigquery/gcs/http)
    processing_metadata: Optional[Dict] = None   # ⭐ NEW: 처리 메타데이터
    
    # 선택적 필드
    usage_unit: Optional[str] = None       # 선택적: 사용량 단위
    
    def __post_init__(self):
        """v2.0 필수 필드 검증 및 보장"""
        # 5단계 보장 시스템: 최종 검증
        if self.cost is None:
            raise ValueError("🚨 CRITICAL: 최상위 cost 필드는 필수입니다. 5단계 보장 시스템 실패!")
        
        # 과학적 표기법 지원 검증
        if isinstance(self.cost, str):
            try:
                self.cost = float(self.cost)  # 과학적 표기법 문자열 → float 변환
            except ValueError:
                raise ValueError(f"cost 필드 변환 실패: {self.cost}")
        
        if self.billed_date is None:
            raise ValueError("billed_date 필드는 필수입니다.")
        
        # 기본값 설정
        if self.tags is None:
            self.tags = {}
        if self.additional_info is None:
            self.additional_info = {}
        if self.data is None:
            self.data = {"cost": self.cost, "list_price": None}  # 기본 data 구조
        if self.processing_metadata is None:
            self.processing_metadata = {
                "cost_guaranteed": True,      # ⭐ NEW: Cost 필드 보장 플래그
                "scientific_notation_supported": True,  # ⭐ NEW: 과학적 표기법 지원
                "version": "v2.0"            # ⭐ NEW: 데이터 모델 버전
            }
    
    def validate_cost_guarantee(self) -> bool:
        """Cost 필드 보장 검증 (v2.0)"""
        return (
            self.cost is not None and 
            isinstance(self.cost, (int, float)) and 
            not (isinstance(self.cost, str) and self.cost.strip() == "")
        )
    
    def get_credits_summary(self) -> Optional[Dict]:
        """Credits Detail 요약 정보 (v2.0)"""
        if not self.credits_detail:
            return None
        
        total_credits = sum(credit.get('amount', 0) for credit in self.credits_detail)
        return {
            "total_credits": total_credits,
            "credits_count": len(self.credits_detail),
            "credits_types": list(set(credit.get('type', '') for credit in self.credits_detail))
        }
```

## 매핑 규칙 모델

### MappingRule
```python
@dataclass
class MappingRule:
    """단일 필드 매핑 규칙"""
    source_path: str  # 예: "project.id"
    target_field: str  # 예: "additional_info.project_id"
    data_type: str = "string"
    required: bool = False
    default_value: any = None
    transformation_function: Optional[str] = None

@dataclass
class MappingRuleSet:
    """전체 매핑 규칙 세트"""
    provider: str
    rules: List[MappingRule]
    auto_mapping_enabled: bool = True
    
    def get_rule_by_target(self, target_field: str) -> Optional[MappingRule]:
        """대상 필드로 매핑 규칙 검색"""
        return next((rule for rule in self.rules if rule.target_field == target_field), None)
```

### ValidationResult
```python
@dataclass
class ValidationResult:
    """설정 검증 결과"""
    is_valid: bool
    errors: List[str] = None
    warnings: List[str] = None
    
    def add_error(self, message: str):
        if self.errors is None:
            self.errors = []
        self.errors.append(message)
        self.is_valid = False
    
    def add_warning(self, message: str):
        if self.warnings is None:
            self.warnings = []
        self.warnings.append(message)
```

## 통계 모델

### FileProcessingStats
```python
@dataclass
class FileProcessingStats:
    """파일별 처리 통계"""
    file_name: str
    file_size: int
    records_total: int
    records_processed: int
    records_failed: int
    processing_start_time: str
    processing_end_time: str
    processing_duration_seconds: float
    throughput_records_per_second: float
    memory_usage_mb: Optional[float] = None
    
    @property
    def success_rate(self) -> float:
        """성공률 계산"""
        if self.records_total == 0:
            return 0.0
        return (self.records_processed / self.records_total) * 100
```
