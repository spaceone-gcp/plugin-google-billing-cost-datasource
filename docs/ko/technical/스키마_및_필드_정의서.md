## 🎯 ABSOLUTE PERFECT ULTRA PURE DATA 원칙

### 데이터 순수성 보장
- **모든 NULL 값 보존**: BigQuery에서 NULL인 값은 절대 기본값으로 변환하지 않음
- **원본 데이터 타입 유지**: 숫자, 문자열, 과학적 표기법 등 모든 데이터를 원본 그대로 보존
- **IFNULL 사용 금지**: BigQuery 쿼리에서 `IFNULL(field, default_value)` 사용 절대 금지
- **반올림/변환 금지**: `round()`, `float()`, `Decimal()` 등 데이터 변환 작업 금지
- **기본값 설정 금지**: `getattr(row, "field", 0.0)` 형태의 기본값 설정 금지

### 스키마 일치성 보장
- **필드 완전 일치**: 응답 필드는 이 스키마에 정의된 필드와 100% 일치해야 함
- **중첩 구조 정확 매핑**: RECORD 타입의 중첩 필드는 정확한 경로로 매핑
- **REPEATED 필드 적절 처리**: 배열 필드는 JSON 문자열로 변환하여 처리

```python
def map_tags_field(row) -> dict:
    """태그 필드 매핑"""
    tags = {}
    
    # 프로젝트 라벨
    if hasattr(row, 'project_labels') and row.project_labels:
        for label in row.project_labels:
            if label.get('key') and label.get('value'):
                tags[f"project:{label['key']}"] = label['value']
    
    # 리소스 라벨  
    if hasattr(row, 'labels') and row.labels:
        for label in row.labels:
            if label.get('key') and label.get('value'):
                tags[f"resource:{label['key']}"] = label['value']
    
    # 시스템 라벨
    if hasattr(row, 'system_labels') and row.system_labels:
        for label in row.system_labels:
            if label.get('key') and label.get('value'):
                tags[f"system:{label['key']}"] = label['value']
    
    return tags
```

#### 3. Data 필드 매핑
```python
def map_data_field(row) -> dict:
    """Data 필드 매핑 (원본 데이터 보존)"""
    data = {}
    
    # 기본 청구 정보
    data['billing_account_id'] = getattr(row, 'billing_account_id', None)
    data['project_id'] = getattr(row, 'project_id', None)
    data['service_id'] = getattr(row, 'service_id', None)
    data['sku_id'] = getattr(row, 'sku_id', None)
    
    # 사용량 세부 정보
    if hasattr(row, 'usage_amount_in_pricing_units'):
        data['usage_amount_in_pricing_units'] = row.usage_amount_in_pricing_units
    if hasattr(row, 'usage_pricing_unit'):
        data['usage_pricing_unit'] = row.usage_pricing_unit
    
    # 크레딧 정보 (REPEATED 필드 → JSON 문자열)
    if hasattr(row, 'credits') and row.credits:
        data['credits'] = json.dumps(row.credits)
    
    # 환율 정보
    if hasattr(row, 'currency_conversion_rate'):
        data['currency_conversion_rate'] = row.currency_conversion_rate
    
    return data
```

### 중첩 필드 처리 규칙

#### RECORD 타입 필드 매핑
```python
def extract_nested_field(row, field_path: str):
    """중첩 필드 추출 (예: project.name, service.description)"""
    try:
        value = row
        for part in field_path.split('.'):
            if hasattr(value, part):
                value = getattr(value, part)
            elif isinstance(value, dict) and part in value:
                value = value[part]
            else:
                return None
        return value
    except (AttributeError, KeyError, TypeError):
        return None

# 사용 예시
project_name = extract_nested_field(row, "project.name")
service_description = extract_nested_field(row, "service.description")
location_region = extract_nested_field(row, "location.region")
```

#### REPEATED 필드 처리
```python
def process_repeated_field(repeated_data: list) -> str:
    """REPEATED 필드를 JSON 문자열로 변환"""
    if not repeated_data:
        return None
    
    try:
        # 리스트를 JSON 문자열로 변환
        return json.dumps(repeated_data, ensure_ascii=False)
    except (TypeError, ValueError):
        # 변환 실패 시 빈 문자열 반환
        return ""

# 사용 예시
credits_json = process_repeated_field(row.credits)
labels_json = process_repeated_field(row.labels)
```

## 🔍 필드 검증 규칙

### 필수 필드 검증
```python
def validate_required_fields(record: dict) -> bool:
    """SpaceONE 필수 필드 검증"""
    required_fields = [
        'cost',           # CRITICAL: 절대 누락 금지
        'provider',       # 필수
        'billed_date',    # 필수 (빈 문자열 허용)
        'currency',       # 필수
        'tags',          # 필수 (빈 딕셔너리 허용)
        'additional_info', # 필수 (빈 딕셔너리 허용)
        'data'           # 필수 (빈 딕셔너리 허용)
    ]
    
    for field in required_fields:
        if field not in record:
            return False
        
        # cost 필드 특별 검증
        if field == 'cost' and record[field] is None:
            return False
    
    return True
```

### 데이터 타입 검증
```python
def validate_field_types(record: dict) -> bool:
    """필드 타입 검증"""
    type_rules = {
        'cost': (int, float),
        'usage_quantity': (int, float, type(None)),
        'provider': (str, type(None)),
        'region_code': (str, type(None)),
        'product': (str, type(None)),
        'usage_type': (str, type(None)),
        'resource': (str, type(None)),
        'billed_date': str,
        'currency': (str, type(None)),
        'tags': dict,
        'additional_info': dict,
        'data': dict
    }
    
    for field, expected_types in type_rules.items():
        if field in record:
            if not isinstance(record[field], expected_types):
                return False
    
    return True
```
